Deviations from a stock `pip install letta`
-------------------------------------------
These were established by the environment probe under /tmp/letta-probe and are
carried into this benchmark unchanged. They are packaging and isolation fixes;
none of them alters memory semantics, tool behaviour, or model output.

1. asyncpg==0.31.0 installed. Absent from Letta's declared requirements; the
   server cannot import its PostgreSQL engine without it.
2. pgvector==0.5.0 installed. Absent from Letta's declared requirements; the
   PostgreSQL ORM import fails without it.
3. Schema bootstrapped from ORM metadata. The wheel ships no usable migration
   bundle. This is the largest reproducibility caveat.
4. letta/constants.py patched so LETTA_DIR honours the environment variable
   instead of hard-coding ~/.letta. Without this the benchmark would read and
   write the machine owner's live Letta state.
5. letta/config_file.py patched so conf.yaml is looked up under LETTA_DIR, for
   the same isolation reason.
6. letta/server/rest_api/app.py patched to check for NLTK punkt_tab locally
   instead of calling nltk.download at startup, because network model/data
   downloads were forbidden for this run.

The exact diffs are /tmp/letta-probe/local-wheel.patch. The full 253-distribution
pip freeze is /tmp/letta-probe/environment.txt.

-----------------

or written.
