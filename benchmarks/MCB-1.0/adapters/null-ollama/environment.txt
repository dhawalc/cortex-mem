==============================================

NON-CONFORMING CONTROL. There is no system under test. This file records the
model and host that produced the control artifact, in the same form as the
conforming adapters' environment records, so the run can be reproduced.

What is under measurement
-------------------------

Tools exposed to the model
--------------------------
memory_insert(label, new_string) ........ appends one line to the string
memory_replace(label, old_string,
               new_string) .............. verbatim line rewrite; empty
                                          new_string deletes the line
send_message(message) ................... ends the turn

These are local Python stubs, roughly 30 lines in total, inside adapter.py.
They are not Letta's tools; they are the minimum needed to let a model express
the same edit vocabulary against a plain string. `memory_replace` returns
"error: old_string not found verbatim" when the line does not match, which is
the same failure mode the real tool has.
